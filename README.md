# 新声 NovaSound · AI 电子音乐与歌曲发布平台

面向全球创作者的人工智能电子音乐与歌曲发布平台。本站每日 12:30 自动创作并上架 1 首 AI 纯音乐 + 1 首 AI 人声歌曲。

- **公网访问**：https://huangwei361.github.io/music-website/
- 品牌：新声 NovaSound（新声人工智能科技有限公司）
- 引擎：Cosmo AI 引擎生态 · AI 作曲 / 编曲 / 混音母带 / 人声合成
- 愿景：成为世界第一的人工智能电子音乐与歌曲网站

## 目录结构

```
assets/                 每日音频（daily-YYYY-MM-DD-1.wav 纯音乐 / -2.wav 人声）
新声NovaSound-音乐发布平台.html  单页网站（自包含，无外部依赖）
```

## 每日更新机制

每天 12:30 由定时任务自动执行：

1. 生成 1 首纯音乐（`assets/daily-日期-1.wav`）与 1 首人声歌曲（`assets/daily-日期-2.wav`）
2. 将昨日「今日新声」的两首作品移入「往期单曲」列表
3. 更新「今日新声」区块与 Hero 迷你试听（标题、日期、音频引用、封面配色）
4. 提交并推送到本仓库

## 本地运行

直接用浏览器打开 `新声NovaSound-音乐发布平台.html` 即可（需与 `assets/` 保持同目录）。
